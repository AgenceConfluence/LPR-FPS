# Lycée FPS — 1v1 blasters en mousse

Map 3D du lycée du Pays de Retz (Pornic) jouable en 1 contre 1 dans le navigateur.

**Jouer :** ouvrir la page, cliquer « Créer une partie », envoyer le lien à l'adversaire. Il clique, et c'est parti.

- Connexion directe entre les deux navigateurs (WebRTC via PeerJS), aucun serveur à gérer.
- Manches chronométrées (1:45), le premier qui élimine l'autre marque, premier à 5.
- Commandes : ZQSD / flèches, souris, clic pour tirer, R recharger, Maj courir, Espace sauter.
